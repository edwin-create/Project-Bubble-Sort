Ruby Bubble Sort
📖 Project Overview

The goal is to implement one of the simplest (but least efficient) sorting algorithms: bubble sort. You will build a method bubble_sort that takes an array and returns a new sorted array in ascending order — without using Ruby’s built-in sort method.

In bubble sort, you repeatedly iterate over the list, comparing each pair of adjacent elements and swapping them if they are in the wrong order. You continue looping until no more swaps are needed, meaning the array is sorted.
